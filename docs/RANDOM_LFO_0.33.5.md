# 再生修正の採用 — IndependentMDX 0.33.5

NOTE-MDX-Workbench v2.9.3、2026-10-13。

採用元はIndependentMDX_0.33.5_Windows_x64_Source.zipです。再生シーケンサーへMP／MAの符号・波形位相・MD待機、曲全体で共有する乱数更新、整数深度演算と符号付き16bit音程の折り返しを反映しています。テンポ変更の適用時刻、遅延発音、音色プログラミング、MHのPMD／AMDバンクビット、キーOFF中の変調も採用しています。

Independent OPM 0.14のKON値は変更せず渡します。旧ホストによるbit 4/5の追加入れ替えは不要でした。DLL本体は変更していません。サンプルDEMOの部分OP音色を生のKON順に合わせています。

Workbench独自のMML位置追従、音色編集、PDX監視と位置保持、オフラインWAVワーカー、設定形式は維持しています。IndependentMDXのファイルセレクターやZIP／LZH閲覧UIを取り込む変更ではありません。

Linux上で採用元とWorkbenchのMRLライターを同じ236曲、2ループで実行し、ヘッダーとイベントを含む全ファイルがバイト単位で一致しました。元の合成プローブとDEMOをソース版の`native/tests/fixtures/IndependentMDX_0.33.5/`へ収録しています。採用元の出力ハッシュは`expected_mrl.json`、再検証手順は`docs/BUILD.md`を参照してください。

この比較は採用元からの移植一致の検証です。実機や別シーケンサーとの一致、全MDXの完全互換性、音源合成の完全一致を保証するものではありません。採用元の乱数式はレジスタ記録から得られた式で、未観測の条件の完全性は確認していません。Windows GUI・実機・外部音声機器での確認は未実施です。
