# VGM / VGZのPCM出力 — 2.10.0

PCM8のP〜Wは各トラックのパン指定に従って左右別々にソフトウェア合成し、ステレオPCMとして出力します。中央パンは同じ波形を左右へ、左パンは左側だけ、右パンは右側だけへ加算し、消音パンは無音です。左右を平均するモノラル化は行いません。音量・発音速度・開始位置は各PCMトラックの指定に従い、FMのパンとYM2151レジスタの時刻列は変更しません。

合成は浮動小数点で行い、62,500 Hzから44,100 Hzへ左右それぞれ区間の重み付き平均で変換してから量子化します。全区間・両側の絶対ピークの最大値が32,752を超える場合は、左右のPCM全体に共通の`32752 / peak`の一定減衰を適用します。それ以外は元の音量を維持します。左右別々の正規化や瞬間ごとの自動音量調整ではなく、ステレオバランスと強弱を維持するための過大入力防止です。FM音量には適用しません。

## 直接PWM DAC形式

| 項目 | 値 |
| --- | --- |
| VGM版 | 1.71 |
| 時刻単位 | 1 / 44,100秒 |
| PWMクロック（ヘッダー0x70） | 23,011,361 Hz |
| 初期化 | PWMレジスタ1へ0、レジスタ4へ0 |
| PCM | 符号付き12bitの2の補数、無音0 |
| データ | レジスタ2へ左、レジスタ3へ右の値を送信 |
| 終了 | レジスタ4へ0 |

IndependentMDX 0.33.5の既存直接DACプロファイルに合わせています。これは汎用の32X PWM制御・FIFOや実機32Xでの再現を保証する形式ではありません。プレーヤー側にYM2151とこの直接PWM DAC形式の対応が必要です。VGZは同じVGMをgzip圧縮したものです。ループ位置とGD3曲名を保持します。チャンネル合成済みのため、出力後にPCM P〜Wへ分離できません。

旧出力はPWMクロック180,545,400 Hz、cycle=4095、無音2047のオフセット符号化でした。IndependentMDXの対応プロファイルから外れ、符号付き12bitとして解釈するプレーヤーでは無音付近の2047/2048境界が大きな波形反転になります。新しい出力では仮想クロックと無音オフセットを使用しません。既存ファイルはMUS/PDXから再出力してください。

## 検証

C++の回帰テストで1・2・8チャンネル、左右パンの分離と非対称バランス、正負の値、過大入力、無音、命令形式、総待機時間、ループを検査します。Actionsでは固定コミットのIndependentMDX本体を別にビルドし、生成したVGMとVGZの読み込み、PCMステレオ再生と左右分離、シークを確認します。一般の全VGMプレーヤーと実機の音声を網羅した検証ではありません。

参考：[VGM 1.71仕様](https://raw.githubusercontent.com/vgmrips/vgmplay-legacy/master/VGMPlay/vgmspec171.txt)、[IndependentMDXの対応範囲](https://github.com/ickaze/IndependentMDX/blob/da0f05b6f032d240d2380bc923db53c57645bfb6/docs/VGM_SUPPORT.md)。参照先のプレーヤー実装はWorkbenchの製品コードへ組み込みません。

## 版による違い

alpha.10では上記のクロック・符号化修正と同時にPCMをモノラル化していました。alpha.11では互換性修正を維持し、PCMのステレオ合成とパンを保持します。左右の分離は既存の直接PWM形式で表現でき、正常再生のためにモノラル化する必要はありません。
