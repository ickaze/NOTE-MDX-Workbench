# アイコンの来歴とライセンス

NOTE MDX Workbenchの青紫・2行ロゴのアイコンです。I.C.KaZe向けにOpenAIの画像生成機能を用い、提供されたIndependentMDX画像の雰囲気を参照して作成しました。文字配置の調整、背景と文字レイヤーの分離・合成、ICOとWindowsリソースへの変換を行っています。完全な手描き作品や特定の既成フォントを使用したものとは表示しません。外部フォントファイルは同梱していません。

配布主体：I.C.KaZe。配布する画像・リソースには、著作権が成立する範囲で[0BSD](../LICENSE.txt)を適用します。AI生成物への権利の成立自体や、参照元に関する第三者の権利を保証する表示ではありません。

- `app-icon.png`：1254×1254ピクセルの採用画像。
- `app.ico`：16～256ピクセルの10サイズ。
- `app.rc`：グループアイコンID 101。
- C++ GUIはCMakeで`app.rc`を直接リンクします。Go用リソースは収録しません。

履歴：v2.9.9で採用。v2.9.10のEXE構造修正とv2.9.11の通知整備では画像データを変更していません。
