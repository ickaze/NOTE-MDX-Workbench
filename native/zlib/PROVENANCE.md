# zlib 1.3.1 compression subset

Unmodified selected files from the zlib 1.3.1 source archive repackaged by Debian/Ubuntu as libz-mingw-w64 1.3.1+dfsg-1. No contrib code is included. Workbench builds only adler32.c, crc32.c, deflate.c, trees.c, and zutil.c, with its own root CMake target. Upstream LICENSE and per-file notices apply; see ../../licenses/zlib.txt.
