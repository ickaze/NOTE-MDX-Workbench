# ライセンス履歴の訂正と実物比較

## 訂正

0.11bへ同梱したVALIDATION_0.11.mdに、対象版を明示しない「バイト単位で一致します」という記述を残していました。現在の0.11bを説明する文としては誤りです。文書更新の不備を訂正します。

保存されている0.10b、当初の0.11、置き換え済み0.11bの3つのZIPを取得し、ハッシュを計算しました。0.10bと当初の0.11については、対象2ファイルの実バイト列も比較して一致を確認しました。0.11bの2ファイルはどちらも異なります。

この不一致を説明するために「別ビルドの0.10bが存在した」と仮定する必要はありません。この訂正記録の実物比較は、当初0.11の検証記録が変更後0.11bへ対象を明示せず残ったことを示します。他の中間版が存在しなかったという証明ではありません。

## この訂正記録の変更範囲

- VALIDATION_0.11.md：対象を当初0.11に限定し、現在の0.11bには一致しないことを明記。
- VALIDATION_LICENSE_UPDATE.txt：途中段階の履歴であり、現在の第三者表示の内容を保証するログではない旨を追記。この途中段階の比較対象ZIP自体はこの訂正時には再検証していない。
- README：訂正へのリンクを追加。
- PACKAGE_MANIFEST.json：現在のファイルハッシュへ更新。

版番号は0.11bを維持する。音源コードやライセンス文自体をこの訂正で変更したわけではなく、コードのテストを再実施したとは記載しない。ハッシュ比較だけで、独立実装やライセンス適用の法的妥当性が証明されるわけでもない。
