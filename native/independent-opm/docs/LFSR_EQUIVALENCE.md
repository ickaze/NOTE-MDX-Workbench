# 観測系列を生成する別の演算表現

結論：同じ周期だけでなく、同じ出力ビット列を生成する別表現がある。従って、17ビットLFSR候補が観測に合うことから、実機にその回路形式がそのまま存在するとまでは言えない。

基準は右シフトFibonacci形、更新前のbit0を出力とする。

    next = (s >> 1) | (((s ^ (s >> 3)) & 1) << 16)

## 具体例

|表現|同じ系列にする条件|
|---|---|
|Galois形|右シフト後、旧bit0が1なら0x12000をXOR。基準seed=1に対しGalois seed=0x4001。更新前bit0を出力|
|XNOR形|状態を17ビット内で反転して表す。帰還をXNORとし、出力も反転。基準seed=1に対しseed=0x1fffe|
|循環バッファ|b[n+17]=b[n+3] XOR b[n]を17要素の循環配列で計算。初期17出力を一致させる|
|GF(2)行列|17ビット更新を行列Aで表す。k段先はA^k s。XORとANDを使う行列演算で同じ状態になる|
|周期表＋カウンタ|131071ビットを約16 KiBに格納し、位相カウンタで読み出す。定常系列は同じになるが、回路の説明にはならない|

初期状態を同じ整数にすればどの表現でも同じ出力になるわけではない。Galois形の一般状態は、その状態から得る最初の17出力をFibonacci状態のbit0〜16へ並べることで対応付けられる。表のマスクはこの出力・シフト・更新タイミングの定義専用で、別の表記へ無条件に移植しない。

research/equivalence/verify.pyで、Fibonacci、Galois、XNOR、循環配列の131071出力すべてが一致し、周期後に各初期状態へ戻ることを確認した。複数初期値の変換と、16段・256段・大きな段数への行列ジャンプも照合した。他のYM2151エミュレータの実装を使った検証ではない。

## 観測から言える範囲

「周期が131071」は「同じビット列」を意味しない。逆に、同じビット列を出す表現は複数あり、有限の録音にだけ一致する別方式も多数作れる。

これまでの録音は定常区間の観測上の漸化式を支持する。一方、乱数源の更新間隔、LFOが取り込む時刻、NFRQ変更、初期化時の状態は別の仕様である。生成器の表現をGalois形や行列へ変えるだけでは、未確定の状態遷移は解決しない。

なお、周期波形で確認した「4ビット反転カウンタの比較」はLFOの進み幅に関する候補であり、ランダム源の17次系列とは別の検証項目。

等価性検証ではエミュレータ本体の乱数生成方式は変更していない。数学的な別表現と、その一致を再検証できる独自コードを追加した。
