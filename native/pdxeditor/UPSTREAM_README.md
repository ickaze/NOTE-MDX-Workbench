# PDXEditor v1.1.1

Windows 10/11用のPDX／EX-PDX PCM編集ツールです。WAVをバンク内の鍵盤へ割り当て、使用範囲・音量・音程・再生方向を編集してPDXへ出力します。

## 主な機能

- バンク000～255、各バンク96音色。標準PDXとEX-PDXの読み込み・出力。
- ADPCM、P16、P8のPCM形式。WAV入力はPCM 8／16／24／32bitと32bit Floatに対応し、多チャンネル入力はモノラルへ合成。
- マウス、PC鍵盤、MIDIによる試聴。試聴音量0～500%は出力データに影響しません。
- 音色ごとの音量0～200%、トランスポーズ−24～+24、WSOLAによる再生時間を維持するピッチシフト。
- WAV範囲選択、ズーム、スクロール、ゼロクロス調整、逆再生、Undo／Redo。
- 日本語／英語、外部言語ファイル。両言語で共通の固定レイアウト。基本配色は作者の別アプリIndependentMDXと共通です（配色のみ）。

## ファイルを読み込む

「設定/PDXを読み込む」では次の両方を選択できます。

| 拡張子 | 内容 |
| --- | --- |
| `.pdxedit` | 編集プロジェクト。WAV割り当てと変換設定を復元 |
| `.pdx` | PCMデータ。解析・WAV展開して編集プロジェクトを作成 |

実行ファイルへのファイルのドロップ起動にも対応します。起動引数は次のとおりです。

```bat
PDXEditor.exe --lang ja "D:\Sound\sample.pdxedit"
PDXEditor.exe "D:\Sound\sample.pdx" --lang en
```

`--lang ja`／`--lang en`、`--lang=ja`／`--lang=en`に対応します。言語とファイルの指定順は自由で、起動引数の言語を保存済み設定より優先します。

プロジェクトを読み込むと、そのフォルダーを作業フォルダーにします。PDXのインポートでは実行ファイルのフォルダーを作業フォルダーにし、PDX名のサブフォルダーへWAVを展開してプロジェクトを保存します。実行ファイルのフォルダーには書き込み権限が必要です。

## 鍵盤・試聴操作

鍵盤はo0～o8の9段です。PDX番号00はo0d#、93はo8c、95はo8dに対応します。番号00～95以外の鍵盤は割り当てできません。

| 操作 | 動作 |
| --- | --- |
| WAVを鍵盤へドラッグ | 選択鍵盤にWAVを割り当て |
| WAV／鍵盤を左クリック中 | 試聴。離すと停止 |
| WAVリスト／鍵盤でEnterを押している間 | 選択音色を試聴 |
| PCキー `AWSEDFTGYHUJ` | 1オクターブを演奏。複数同時押し可能 |
| 矢印キー | 選択を左右へ1音、上下へ1オクターブ移動 |
| 鍵盤クリック中にホイール | トランスポーズを変更 |
| 鍵盤の右クリック | 割当削除／登録済みWAVの割当 |
| Delete | 鍵盤割当または選択WAVを削除 |
| Ctrl+Z | Undo（最大100手） |
| Ctrl+Shift+Z／Ctrl+Y | Redo |

MIDI入力はNote On／Off、Velocity、Program Changeによるバンク0～127の切替に対応します。アフタータッチは反映しません。デバイス候補はコンボボックスを開くたびに再検出します。

WAVリストではShift／Ctrlによる複数選択とCtrl+Aが使えます。削除したWAVを参照する鍵盤の割当も解除します。リストの列はパス・ファイル名・タイムスタンプ・サイズ・長さ・周波数・ビット数・チャンネル・形式です。列クリックでソートできます。

試聴中のWAVリストには固定した波形全体とオレンジ色の再生位置を表示します。リスト／ログ間の境界は上下にドラッグできます。

## 波形編集

- 波形の左ドラッグで使用範囲を指定。左から右は正方向、右から左は逆再生です。
- 正方向は緑、逆方向は赤の半透明表示。開始・終了位置とサンプル数を表示します。
- 端点付近をドラッグするとその端だけを変更し、再生方向は維持します。
- ホイールでカーソル位置を中心に拡大縮小。ドラッグ中も使えます。上部スクロールバーで表示範囲を移動します。
- 右クリックから開始・終了・両端の内側／外側ゼロクロス検索と再生方向切替を行えます。
- 波形エディターのCtrl+Aで全範囲を選択。再生方向は維持します。
- 波形エディターのEnter／スペースで選択範囲を試聴。離しても最後まで再生し、再度押すと再開始します。キーリピートでは再開始しません。

試聴と出力は、範囲切り出し、必要な場合の逆順化、音量・音程処理、15.625kHzへの変換、PCM符号化を共通で適用します。ピッチシフトを無効にすると、音程に応じて再生時間も変わります。

## 保存とPDX出力

| 保存先 | 保存内容 |
| --- | --- |
| 実行ファイル横の`PDXEditor.ini` | ウインドウ位置・サイズ、列幅、分割位置、言語、試聴音量、オクターブ、MIDI設定、最終プロジェクト |
| プロジェクトフォルダーの`<pdxName>.pdxedit` | PDX名、出力形式、元形式・元PDX、現在バンク、各音色のWAV・音量・音程・使用範囲・再生方向 |

設定と編集内容は自動保存します。レジストリ、AppData、ユーザープロファイルへの保存や別保存先へのフォールバックは行いません。旧プロジェクトの共通設定はINIにない項目だけ引き継ぎます。INIに`lastProject`項目がなければ実行ファイル横の`PDXEditor.last`を読み込みます。明示的な空値では旧ファイルを採用しません。

WAVがプロジェクトフォルダー以下にある場合は相対パスで保存します。それ以外は絶対パスです。

「変換/PDX出力」で指定形式のPDXを出力します。最後にデータが存在するバンクまで、先頭・途中の空バンクも番号を保持します。末尾の空バンクのみ省略します。インポートした音色が無編集の場合は元PCMを保持して再出力します。

標準PDXの16bit長とEX-PDXの32bit長、非0予約領域、ヘッダー後のパディング、不完全な旧ヘッダーの互換処理を含みます。形式推定は完全な判定を保証しないため、読み込み後の形式と試聴結果を確認してください。LZX042圧縮PDXは未対応で、デコーダは含みません。

## ビルドと配布

Visual Studio 2022の「C++によるデスクトップ開発」とWindows SDKが必要です。ソースはC++17、UTF-8です。外部音声ライブラリは不要です。

MSVCではReleaseを`/MT`、Debugを`/MTd`でビルドします。この設定で再ビルドしたRelease版はVC++再頒布可能パッケージの別途インストールを必要としません。Windows標準DLLへの依存は残ります。以前の動的リンク版EXEの依存関係は、ソース設定だけでは変更されません。

リンカーに`/PDBALTPATH:%_PDB%`を指定し、EXE内のPDB参照をファイル名だけにします。PDBの作成先は変えず、PDBは公開用ZIPに含めません。設定変更後は`Release | x64`をリビルドしてください。

### Visual Studio／BAT

`PDXEditor.sln`を開き、`Release | x64`でビルドします。または`build_vs2022.bat`を実行します。BATは`vswhere.exe`を使用せず、PATH、`VS2022_PATH`、`VSINSTALLDIR`、標準インストール先の順にMSBuildを探します。

```bat
set VS2022_PATH=D:\VisualStudio\2022\Community
build_vs2022.bat
```

`CI`環境変数が定義されている場合は終了時の`pause`を省略します。

出力先は`x64\Release\PDXEditor.exe`です。MSBuildのビルド後ターゲットが`languages`とLICENSE・README・CHANGELOG・依存関係・検証記録を実行ファイル横へコピーします。

### CMake（Windows）

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

出力は`build\Release\PDXEditor.exe`です。CMakeも日本語／英語ファイルと配布文書をコピーします。追加言語を配布する場合は、その`.lang`も実行ファイル横の`languages`へ配置してください。

EXEを配布するときは`languages`フォルダーとコピーされた文書を一緒に配布してください。言語ファイルが欠落した場合や翻訳キーが不足する場合は内蔵英語を使用します。既存のINIやユーザー作成プロジェクトはビルド後コピーで上書きしません。
