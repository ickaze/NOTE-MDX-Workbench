# CHANGELOG

日付はソース配布物の整理日です。過去の公開日を確認できない版は「日付未記録」としています。

## v1.1.1 — 2026-10-11

- MSVCランタイムをRelease `/MT`、Debug `/MTd`へ変更。Visual StudioとCMakeの設定を統一。
- `/PDBALTPATH:%_PDB%`を追加し、EXE内のPDB参照からビルド先の絶対パスを除去。
- 公開用パッケージ方針を単一の最上位フォルダーへ統一し、未署名バイナリの案内を追加。

- 0BSDのLICENSE、著作権表示、依存関係の説明、検証記録を追加。
- CI環境ではbuild_vs2022.batの終了待機を省略（CI環境変数が定義されている場合）。
- Visual StudioとCMakeのビルド後に言語ファイルと配布文書を実行ファイル横へコピー。言語ファイル欠落時の英語フォールバックを追加。
- READMEを現行仕様へ統一し、開発版の記述を変更履歴へ整理。
- 上部を操作ボタン／言語選択とPDX名／形式／バンク／MIDI入力の2行に変更。初期幅を1000ピクセルとし、日本語／英語で固定配置を共有。
- 音量とトランスポーズのスライダー・数値欄を整列。スライダーはクリック位置へ直接移動。
- 作者の別アプリIndependentMDXと同じ基本配色を適用（配色のみ）。
- 起動引数で言語とプロジェクト／PDXを指定可能。
- MIDI入力候補をコンボボックス展開時に再検出。
- 共通設定と最終プロジェクト情報をPDXEditor.iniへ分離。PDX制作情報はプロジェクトに保存。
- INIにない共通設定項目は旧プロジェクトから引き継ぎ、最終プロジェクト項目がない場合はPDXEditor.lastを読み込み。
- プロジェクト切替・インポート・Undo/Redoで共通設定を保持。
- 波形エディターのCtrl+A、右から左の範囲選択による逆再生、右クリックの方向切替、方向別の緑／赤表示を追加。
- 波形エディターのEnter／スペースによる選択範囲試聴を追加。長押しによる再開始を抑止。
